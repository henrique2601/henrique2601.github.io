# Angel Brandão Beauty — website

Static site in Dutch for angelbrandao.nl (permanente make-up, Almere).

- Content + templates: `scripts/build.js` (all texts, prices, FAQ live there)
- Styles: `src/assets/style.css`
- Images: `src/assets/img/`, icons: `src/assets/icons/`
- Build: `node scripts/build.js` → `dist/`
- Preview: `cd dist && python3 -m http.server 8787` → http://localhost:8787
